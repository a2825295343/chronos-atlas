一个可本地运行、核心地图无需联网的世界历史地图浏览器。React 19 + TypeScript + Vite + MapLibre GL JS 6。界面为中文，适用于支持 WebGL 的现代桌面浏览器。

## 运行

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。也可以直接双击 `启动观澜.cmd`（使用 Python 标准库运行已构建版本，无需安装 Node.js 依赖），或执行 `python start.py`。已经随项目保存地图素材，正常使用无需重新下载。构建生产版本：

```powershell
npm run build
npm run preview
```

`dist/` 可由任何静态 HTTP 服务器提供。不要直接双击 index.html，浏览器需要通过 HTTP 加载数据和工作线程。

## 数据覆盖与明确限制

这是具有真实地图数据的可运行初版，**不是已经完成的全球逐年历史数据库**：

1. 疆界按源记录的有效区间筛选，不代表每年重新考证。全量做了结构、日期和几何检查，并修正 1444 年统一蒙古帝国、罗马／汉朝实体错配等已发现问题；**不能承诺所有历史边界都已完成专家审定**。源数据仍有缺口，例如明朝建国后的最初几年未收录同名疆界。
2. 史前文化与古人类分布不代表国家。古代疆界、宗属与海岸线存在不确定性与争议。
3. 虚线行政区使用现代 Natural Earth 参考边界，**不代表古代行省，也不会伪装成随历史变化的真实省界**。历史地名只覆盖手工整理的地点序列；其命名粒度与省份不同。
4. 占领示意目前只覆盖 1915—1917 年比利时、1941 年法国，使用手工概化范围。**没有覆盖所有战争或实时战线**，不适合精确军事研究。
5. 档案覆盖仍不完整。人口、GDP 与军队人数只展示对应年度观测；外交未检出记录不能推断为没有盟友或处于和平。COW 数据库截止年不能当作条约真正终止年；联姻表示家族纽带，不等于军事结盟。同年继位时列出交接双方，不表示全年共同统治。明朝网络常见“国旗”被标明为虚构，因此未用作真实国旗。
6. 地形与海岸线来自现代地理资料。不能认为在史前或古代完全一致。

## 更新或扩充资料

高清地形在 Python 启动器运行时按需下载，缓存在 `.local/terrain/`。只从固定的 AWS Terrarium 来源读取公开瓦片，不需要 API 密钥。原始历史疆界的概化精度不会因为更细的地形和更高渲染分辨率而改变。

```powershell
python scripts/download_data.py
python scripts/prepare_provinces.py
python scripts/download_terrain.py
python scripts/download_statistics.py
python scripts/prepare_ocean.py
```

下载脚本可续传已经存在的完整文件。历史数据以 `public/data/manifest.json` 和对应的 GeoJSON 文件组织；事件、地名、档案和占领范围在 `src/data.ts`。扩充资料时必须同时给出来源、适用年份和精度说明。

重新生成高清海洋遮罩或中文词表时，可先运行 `python -m pip install --target .local/python -r scripts/requirements-data.txt` 安装构建资料所需的可选依赖；日常启动软件不需要这些依赖。海洋遮罩分为较小的多边形，减少全球复杂多边形的三角化伪影，不改变海岸形状。

`npm test` 检查时间轴、快照选择、跨纪元年份、球面面积及离线数据完整性；`npm run build` 执行 TypeScript 检查和生产构建。

## 后续完整数据库所需

目前已经具备有来源的有效期疆界与实体 ID。要实现完整历史行省、全球占领战线和全部年度档案，仍需逐地区补全史料与精度审查；地图未用猜测填满空白。

地形动画适配器固定使用 MapLibre 6.16.0 的地形状态布局，复用 GPU 网格，并同步 CPU 高程采样和深度缓存；若运行时结构不匹配则回退到公开 setTerrain API。升级地图引擎时需复测该适配器。

## 战争、控制区与交互优化（2026-10-30）

- 右侧“战争”和地图战争入口展示当前年份全部**已收录**战争与武装冲突，可搜索、按强度筛选、进入双方与细节档案。数据库共 1,058 条战争／冲突记录：COW 体系内、体系外、国内和非国家战争；UCDP/PRIO v26.1 的 2,816 条年度活动记录；15 项古代至近代重点战争补录。不同资料的定义及强度门槛不同，不是全球战争的穷尽目录。
- 原始数据与出处：COW <https://correlatesofwar.org/data-sets/cow-war/>；UCDP <https://ucdp.uu.se/downloads/>（CC BY 4.0；Davies、Pettersson、Öberg，2026，doi:10.1093/jopres/xjag046）。COW 官方下载连接不可用时采用同版本学术镜像 <https://github.com/mateosuster/cow_data>，原始 CSV 与编码手册保存在 `.local/conflicts`。
- COW NMC 的历史国家年度序列覆盖1816—2012，共15,171条有效国家年记录；原始“千人”单位已转换为“人”。原文件 `NMC_5_0.csv` 取自原有学术来源 <https://github.com/hwalbert/diss_repo>；编码手册 <https://correlatesofwar.org/wp-content/uploads/NMC_Documentation_v5_0.pdf>。源行 `version` 字段原样记录于元数据，不冒称最新版 NMC7。全国军事人员不等于特定战区兵力。
- 战区峰值与全国军事人员分别标注；仅在同一实体、间隔不超过5年的两条观测之间进行线性兵力插值，并标明估算及依据年份。数据缺项不生成精确数字。战争原因有史料概述或明确标注的分类推断；未编码的胜负不臆定。二战流亡政府／海外武装参战另按 RAF Museum 和 National WWII Museum 资料补充。
- 加入西欧部分德占区和战后德国军事管理区。底层政权几何按控制区切分，避免重复计算覆盖面积；斜线使用控制方颜色，点击查看主权方、控制方与精度。战后德国占领分区主要用现代州界组合近似重建，西南分界概化，柏林以四国共管整体表示。临时政权保留独立原始记录，不把同盟或援助关系自动画成领土。
- 增加784条与职位明确匹配的统治者／政府首脑任期，唐、宋、元、蒙古等重点君主在位表及21幅经人物身份核对的画像。任期交接年可能同时列出多人，画像可能为后世绘像，不等于真实相貌复原。
- 国名沿内部路径逐字排布、拉开间距并轻微弯曲；小国使用完整紧凑标注。主标签离开视口时，在当前可见国土内补显示国名。放大时与地块名渐变切换。
- 时间拖动的即时反馈在独立组件内更新；180ms合并后台请求，松手立即提交最终年份。后台线程计算疆界、边线、面积与标注，同一有效期内复用；高倍视角才生成地块图层。Node本机计算样本约16ms（100年）、48ms（1444年）、171ms（1941年）、105ms（1960年），均移出界面主线程；这些是计算时间，不是端到端帧率承诺。
- 海面使用按地理海洋遮罩裁切的轻量波纹动画；页面隐藏及系统要求减少动态时停止动画。
- 界面、政体、行政区类型与常见战争名已人工校正。703条缺中文的英文简介提供基于类别与地理线索的中文简述，原文仍在资料页；不把简述说成全文翻译。批量翻译服务限流，未完成的少数专名保留原文。

后续重建占领控制区：先完成原始时序命名流程，再依次执行 `prepare_control_areas.py`、`apply_control_areas.py`、`finalize_chinese_text.py`，最后 `npm run build`。控制区脚本备份原始世纪分片后重建，可重复运行。


## 势力配色跨年稳定修复

旧版在每次查询年份后，根据该年的疆域大小与邻国重新贪心着色，邻国或面积变化会触发连锁换色。现在运行时只按固定势力身份查表，颜色不受年份、浏览方向、领土面积、记录排序与邻国出现／消失影响。常见国家的改名及政权时期别名合并为同一配色身份；分立国家、独立历史政权仍可分别着色。

固定表 `src/color-registry.mjs` 覆盖4,280个身份。配色在离线阶段参考全部时期的22,803条空间邻近关系预先规划，主要势力设置固定色，相邻颜色接近时继续依靠深浅双层国界和占领斜线区分。占领线、势力索引和地图填色共用同一身份配色入口。未收录的势力采用稳定名称哈希。

`node scripts/prepare_stable_colors.mjs` 是显式的离线规划命令，普通启动、构建和时间切换不会重新生成配色表。新增回归检查覆盖跨年和倒序查询、邻国增减、领土大小变化、别名、主要邻国色差及占领线颜色。

## 法国旗帜与缩放填色修复

上游 `Kingdom of France` 曾误指向波旁复辟实体 Q207162，导致1415年显示未限定年代的纯白旗。现将其身份修正为法兰西王国 Q70972，并迁移对应君主任期及画像映射；1376—1589年采用有出处的蓝底三朵金色鸢尾花王室纹章旗，界面明确标为王旗。旗帜资产、作者和许可保留在 `public/data/flags.json`，1376年三花纹章依据见 <https://en.wikisource.org/wiki/1911_Encyclop%C3%A6dia_Britannica/Fleur-de-Lis>，原图见 <https://commons.wikimedia.org/wiki/File:Royal_flag_of_France.svg>。纯白旗只保留在复辟时期条目中，不再跨时代套用。

现代法国在低倍视角出现的暗色大块来自瓦片整数化：极小离散外环可能翻转方向，使同一个 MultiPolygon 的大陆主体被误判为孔洞。现在仅将绘制输入拆成独立 Polygon，隔离离散外环的方向判断；原始历史坐标、真实内洞、国家身份、面积计算与档案仍保留。占领绘制使用同一处理。`tests/france.test.mjs` 检查1960、2000、2001、2024年在1—5级瓦片上的本土覆盖、真实内洞及王旗年代；实际页面核验截图为 `docs/france-1415-fixed.png` 和 `docs/france-2000-fixed.png`。

## 全球时序核查与细分

运行 `python scripts/refine_chronology.py` 在现有命名、殖民地区及控制区构建完成后应用可追踪的修订，再运行 `python scripts/audit_chronology.py` 生成全球报告，最后 `npm run build`。第一次执行会在 `.local/chronology-originals/` 保存修订前分片；重复执行从同一备份重建，不累积切分。若重新下载了上游资料，应保留旧备份另作版本迁移，不能将该备份当成新上游。补全已复核实体元数据的命令为 `python scripts/enrich_chronology_identities.py`，使用维基数据官方接口及本地缓存。

60条有年代条件的规则（其中23条为本次现代身份修正）纠正罗马共和国、叙利亚、斯特拉斯克莱德、卢森堡、立陶宛、普雷佩查、也门塔希尔、朝鲜王朝、先秦诸国、越南历代等实体或政权名称错误；原始编号保留在 `sourceQid`。跨时代同名实体按记录年代分别关联，不能用全局名称覆盖所有时期。核对记录与链接保存在 `public/data/chronology-corrections.json`，后继政权依据在 `public/data/chronology-successions.json`。

中国与蒙古补入1368、1369、1370、1371、1382、1387年的事件分期，区分明朝、北元、云南梁王与四川明夏；1911—1925年区分博克多汗国、自治阶段、北洋军控制、1921年革命与1924年人民共和国。1923年中国不再以国民党组织代替国家，但现有轮廓仍不能表现全国军阀的实际控制分界。新补区域按年末代表状态显示，使用历史GIS及现代地理区遮罩作概化重建，精度和史料在档案中明确说明。

时间输入和拖动按年查询，自动播放默认逐年，等待当年查询返回后继续推进；缓存复用相同的有效轮廓。没有新边界资料的连续年份共享有出处的分期数据，**没有通过插值或复制文件声称获得完整的逐年精确疆界**。

1917—1929年缺失的东北及相邻内蒙古部分，采用1914年中华民国历史轮廓与现代地理遮罩补入国家范围，保留既有租借地区空缺；档案另说明奉系及张学良的地方实际控制。该填色不能解释为中央政府直接管辖。相关史料见邝智文的东北战争研究：<https://scholars.hkbu.edu.hk/en/publications/war-and-geopolitics-in-interwar-manchuria-zhang-zuolin-and-the-fe/>。

全球扫描覆盖55个分片、17,761条去重后的有效期记录和5,424个年度查询，逐一检查日期与几何；并对照可获得的实体存续年代，对全球25个关键年份作空间交叉检查。本轮结构错误为0，仍有162项年代关联线索、57组空间重叠线索需要进一步核定。部分线索源于前身／后继、独立与改制的不同口径，不能自动删除领土。长时期沿用轮廓亦单列公开。上述检查**不等于全球每条历史边界已获史学核定**。

从“数据与来源”或国家档案“资料”进入 `/audit.html`，可筛选已修正、年代待复核、空间重叠和长期沿用清单；完整数据见 `public/data/chronology-audit.json`，文本说明见 `docs/chronology-audit.md`。存在年代差异的国家档案展示待复核提示。


## 现代国旗、元首及政府首脑补全（2026-10-30）

修正奥地利、匈牙利、丹麦、几内亚等23项跨实体／跨时代错误关联。重新读取190个现代国家及领地实体的完整旗帜和任期声明，保留原有历史记录。检查范围为现有地图的187个国家、5个海外领地、3个非国家控制分组；该数量不等于完整的联合国成员国名录。

2024年与2026年的187个国家记录均有可用旗帜、按年筛选的元首状态及政府首脑记录；领地另列。总统与总理分别展示照片、任期和出处。年度交接可能显示数人，不表示同时任职。瑞士采用联邦委员会这一集体元首，黎巴嫩2024年的总统空缺明确说明；军事实控区的控制方领导人与主权归属分开。没有统一领导的武装分组不能凭空填入一名国家元首。

只按明确对应的国家职务任期、制度安排或独立官方记录补全，推定关系标示依据；不按固定任期长度猜测，也不把反对党领袖、其他部长的任期当成元首任期。2026年单年观测不会向过去回填，开放任期以核对年份为展示上界。对应字段仍可能存在上游遗漏或争议，覆盖率表示字段可用，不代表全部史实独立审定。另逐项对照人物的相应职务终期：2024年6条、2026年18条国家记录仍有未封闭国家声明与人物任期的异文；界面标示待复核，报告可筛选，不把异文记录当作已确认现任。

可在“数据与来源”或国家档案“资料”页进入 `/modern-archive.html`，按年、国家名、缺项和补全记录筛选。报告包含旗帜及原图许可链接、元首、政府首脑、首都及政体可用情况。`public/data/modern-term-evidence.json` 保存逐项补全依据；原始接口快照缓存在 `.local/modern-archive/2026-10-30/`。
