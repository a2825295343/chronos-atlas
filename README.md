# 观澜 · CHRONOS

观澜是一个可在本地运行的中文世界历史地图浏览器。这是项目的初版。你可以沿时间轴探索不同时代的版图，查看地图上的政权、战争、历史地名与人物档案。

> **AI 生成与准确性声明**
>
> 本项目全部由 AI 生成，包括代码、文档，以及对历史地图和资料的整理与呈现。项目内容不代表仓库所有者或任何个人的立场。
>
> 项目可能包含大量错误和疏漏，包括历史疆界、控制范围、年代、人物、旗帜和统计数据。引用前请对照独立史料核实。

## 快速开始

需要支持 WebGL 的桌面浏览器，以及 Node.js 20.19+ 或 22.12+（22 或更新的主版本）。

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址。

如果想用 Windows 启动器，先执行 `npm run build`，再双击 `启动观澜.cmd`。启动器需要 Python 3，默认地址为 `http://127.0.0.1:8877`。也可通过 `npm run preview` 预览生产构建。构建产物在 `dist/`，通过 HTTP 访问。

## 地图与档案

- 拖动时间轴、输入年份，或逐年播放。也可按版图变化节点播放。
- 缩小切换到可旋转的地球仪，放大查看立体地形、历史地名和省级参考区。
- 点击政权、首都或省份查看档案。开启省份图层后，放大时可左键查看省份、右键查看国家。
- 按年份查看已收录的战争、占领区和外交关系，以及有资料的旗帜、统治者、政体、人口和经济指标。
- 支持中文搜索、时代书签和地图 PNG 导出。

## 如何阅读地图

历史疆界按数据记录的有效年份展示，精度随地区与时代而异。部分边界是概化重建，战争期间的控制范围和交接日期可能缺失。史前图层包含考古文化与人群活动范围。部分省级轮廓沿用现代地理参考，具体依据可在档案中查看。缺失的档案字段会标明待核实。

地图和基础地形数据随仓库提供。Python 启动器可联网按需获取更高缩放级别的地形瓦片。

## 数据来源与许可

- 历史疆界来自 Cliopatria / Seshat 和 Historical Basemaps。参见仓库内的 [Cliopatria 许可](public/data/CLIOPATRIA_LICENSE.md) 与 [Historical Basemaps 许可](public/data/HISTORICAL_BASEMAPS_LICENSE.txt)。
- 海岸线、水系和现代行政区参考 Natural Earth。地形使用 Terrarium 高程数据。
- 旗帜和肖像的出处与许可可在档案中查看，也分别记录于 [旗帜索引](public/data/flags.json) 和 [肖像索引](public/data/portraits.json)。
- 项目许可见 [LICENSE](LICENSE)。第三方资料适用各自的许可。
