2026-10-29，在 Windows / Python 3.12 / Node.js 24 环境验证。

- `npm run build`：TypeScript 检查与 Vite 生产构建通过。
- `npm test`：5 项通过，覆盖时间轴单调性及反向映射、无公元 0 年、快照回退、带孔和多多边形球面面积、54 份疆界与 4596 个参考区完整性、世界银行数据的经济体身份与年份范围。

## 高清样式与中文名称更新

- 生产构建通过，8 项自动测试通过。新增检查覆盖 3017 个历史名称的中文显示、1365 个全球高程缓存瓦片、详细地理数据和同宗主势力边界去重。
- 画布像素密度提升至 2—2.5；地图字体改用离线 Noto Sans SC；移除宽重光晕，调整为清晰的深色中文标注、柔和区域色与细国界。
- 全球离线地形从 zoom 3 提升至 zoom 5，并通过 Python 本地服务按需缓存更高缩放级别的真实高程。浏览器中验证了长安附近 zoom 8 地形的获取与缓存，未出现资源错误。
- 海岸、湖泊和河流改用 Natural Earth 1:1000 万矢量；现代参考分区简化容差从 0.025 度降至 0.003 度。省级标签改为每个区域一个独立锚点，避免随瓦片重复。
- 中文词表区分人工常用译名、中文百科对应名称、自动译名与暂用音译；后两类在档案中标注待核定。汉化覆盖不等于所有译名都已经过专家审定。
- 发现并修复高清海洋遮罩在撒哈拉附近的三角化横条伪影：将全球海洋切为 71 个小面，面积相对误差小于 1.3e-14；浏览器复核横条已消失。收起覆盖国名的装饰标题，使地图优先显示地名。
