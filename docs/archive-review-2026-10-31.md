# 历史资料与地图名称修订（2026-10-31）

## 地图名称

- 荷兰殖民台湾改为“荷属台湾”，独立领地身份为 `local:dutch-formosa`，上层政权为当时的荷兰共和国，政府说明写明荷兰东印度公司及巴达维亚公司当局。现代中华民国的名称不变。殖民地生成器使用地理名称，避免把现代政体全称套到历史殖民地。
- 那不勒斯地图名称改为“那不勒斯王国”；1806年以前的记录不再关联拿破仑时期的专门实体。霍亨索伦等名称删除英文条目消歧说明。
- 地图文字与档案说明分开：法国占领区地图只写“法国”，德国各占领管理区只写“德国”。控制方、条纹、领土类型、年代和详细管理说明继续保留。字形、视口补充标签与国家填充标签都采用同一地图名称函数。
- 荷属开普殖民地及巴达维亚共和国管理阶段使用开普殖民地地名，避免将总督职位当作领地名称。

## 本批历史修正与补充

- 普鲁士1701—1918年使用9位具名国王，不把“普鲁士国王”这个职位实体当成人物。
- 全球职位补录277条任期资料；罗马、东罗马与塞琉古等专门名录补录281条；印度、萨珊、马里、印加、阿兹特克、科提、康提、哲德沙尔等补录81条。各阶段有独立复核报告、人物身份和任期来源。年内交接、共治及不同纪年可能并列，不能解释为所有人全年同时任职。
- 432条有年代的政体、宗教礼制及政治中心资料；另244项由王国、共和国等明确称谓作最低限度制度推断，均标明推断，不从国家名猜测宗教。
- 新增36条古代、中世纪及早期近代战争概览，补录目录共51条，包含主要阵营、原因、结果、战区与资料链接。元朝两次进攻日本保留1274、1281两个活动年；未把两次战争之间的年份填成持续交战。
- 奥斯曼早期白色占位旗改为依据FIAV研究中红底横向新月海军旗记载的基本几何复原。1362年前的回溯参考与此后的文字史料复原分别标注，不能当作确证的早期全国国旗。
- 锡兰1236—1506年不再引用英属锡兰身份与殖民旗；1412年起分出科提，1469年起分出康提，并保留贾夫纳。科提采用有来源的博物馆旗式重绘，注明不是1506年遗存原物。
- 修复1895—1897年卡扎尔伊朗与荷属东印度的地理错置，并保留伊朗原有小块几何。
- 利沃尼亚改为邦联政治实体，不再关联利沃尼亚语；补充萨克森诸公国等神圣罗马帝国领地关系和奥斯曼北非宗主关系，不把摩洛哥列为奥斯曼附属国。
- 分列新疆1864—1882年清朝、地方政权、哲德沙尔、伊犁与俄军占领阶段；1943—1944年利比亚英国及法国管理区；1941—1944年埃塞俄比亚复国及英国军事管理区；1917—1920年美索不达米亚与1918—1919年黎凡特过渡管理区。大马士革属内陆东区，不属于沿岸西区。
- 印度、东欧、非洲、美洲部分遗漏使用有参考图源的保守核心或前后快照共同范围补绘。843条分期修订涉及55个名称，发布时删除了2条被后续修订替代的中间几何，属于有明确方法说明的概化补绘；不是逐年重新测绘，也不是所有空白都已完成核定。

## 资料边界

地方社群或多邦集合没有统一君主，不虚构一个共同王名。传统纪年、同年交接和早期国家边界仍存在研究分歧。战争的主阵营列表未穷尽全部地方辅助部队；没有统一日期和统计口径的兵力，继续说明缺项，不能用伤亡数或臆造数字代替。年度查询可用不等于每年都有独立历史边界证据。

## 复现顺序

领土阶段保存首次输入备份，后续更正必须按顺序叠加，不能把某个旧备份阶段单独运行后直接发布：旧区域修复 → `repair_archive_identity_errors.py` → `repair_expanded_historical_gaps.py` → `deduplicate_expanded_periods.py` → `repair_oeta_interiors.py` → 全球职位与古代名录apply → `supplement_reviewed_reigns.py` → `apply_global_historical_context.py` → `repair_colonial_names.py` → `repair_display_names.py` → `repair_archive_relationships.py` → `localize_reviewed_people.py` → `supplement_early_wars.py` → `merge_historical_wars.py` → 旗帜及肖像媒体合并 → 时序与战后档案审计 → 测试与构建。

君主身份下载与apply使用可恢复缓存；遇到429限流保留已完成部分，不连续请求剩余页面。

76项自动测试通过，TypeScript与Vite生产构建通过。逐点检查包括喀什、乌鲁木齐、伊犁、哈密，的黎波里、班加西、塞卜哈，亚的斯亚贝巴、阿斯马拉，巴格达、大马士革、贝鲁特，科提、康提，德黑兰和雅加达。全量时序审计覆盖55个分片与5424个年度查询；仍保留未核定的元数据和空间重叠线索，不据结构检查通过宣称史实完全无误。
